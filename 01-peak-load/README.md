# Анализ пиковой нагрузки сервиса

**Учебный проект по аналитике данных и алгоритмам на Python.**

## О проекте

Проект посвящён анализу нагрузки онлайн-сервиса во время высокой пользовательской активности.

Цель — определить максимальную суммарную нагрузку на сервер и самый ранний момент её достижения.

## Данные

Каждый запрос содержит три параметра:

- `start` — начало выполнения запроса;
- `end` — завершение запроса;
- `cost` — потребление вычислительных ресурсов.

Для первоначального анализа использованы примеры из условия задачи. Для проверки производительности — сгенерированные тестовые данные.

## Подход к решению

Сначала рассмотрен простой перебор моментов времени. Затем реализован более эффективный **метод событий (Sweep Line)**.

Алгоритм учитывает начало и завершение каждого запроса, группирует изменения нагрузки по времени и находит максимальное значение.

**Сложность:** `O(n log n)` по времени, `O(n)` по дополнительной памяти.

## Результаты

- На первом примере максимальная нагрузка составила **109 единиц в момент времени 5**.
- Алгоритм прошёл 5 подготовленных тестов.
- На 200 000 запросов время выполнения составило **0,107 секунды** в одном локальном измерении.

## Используемые инструменты

Python 3.12, pandas, matplotlib, Jupyter Notebook.

## Структура проекта

- `analysis.ipynb` — исследование данных, сравнение подходов, визуализация и тестирование.
- `solution.py` — реализация алгоритма на Python.
